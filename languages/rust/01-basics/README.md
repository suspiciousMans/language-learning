# 01 — Basics

**Difficulty:** beginner · **Prerequisites:** 00

## Goals

- Write and run simple Rust programs.
- Understand variables, scalar types, functions, and control flow.
- Get a feel for the compiler's error messages.

## Concepts

- `let` bindings, `mut`, and shadowing
- Scalar types: integers, floats, `bool`, `char`
- Functions: parameters, return values, expressions vs statements
- Control flow: `if`/`else`, `loop`, `while`, `for`
- Ownership basics: move vs copy semantics for scalars

## Completion checklist

- [ ] Complete each exercise file in `src/`.
- [ ] All exercises compile and pass their tests.
- [ ] You can explain, in your own words, what `mut` does and why shadowing exists.

## Starter files

- `Cargo.toml` — library crate for the exercises
- `src/lib.rs` — entry point that re-exports exercise modules
- `src/exercise_variables.rs` — let/mut/shadowing
- `src/exercise_types.rs` — scalar types
- `src/exercise_functions.rs` — functions and expressions
- `src/exercise_control_flow.rs` — if/loop/while/for
- `src/exercise_ownership_basics.rs` — move vs copy for scalars
