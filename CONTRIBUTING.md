# Contributing

## Adding a new project to an existing language repo

1. Pick the next number in the sequence (see PROJECTS.md).
2. Create `projects/<NN-name>/` with a README.md.
3. The README must contain: goals (what you learn), concepts (the new ideas), completion checklist (what "done" means), and any starter files, hints, or solution pointers.
4. Add a row to PROJECTS.md.
5. If the project has exercises, put them in the project folder. If it has tests, add them under a `tests/` or inline as appropriate for the language.

## Adding a new language

1. Create a new repo named `<language>-learning`.
2. Copy this template's README.md, PROJECTS.md, CONTRIBUTING.md, and .gitignore.
3. Tailor every file to the language — especially PROJECTS.md (which projects apply, what each teaches).
4. Seed each project folder with its README and any code/test files.
