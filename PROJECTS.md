# Project Progression

Each project is listed in the order you should do them. Difficulty
increases throughout. The capstone at the end is a real-world project.

| # | Project | Difficulty | Concepts introduced | Prerequisites |
|---|---------|-----------|---------------------|---------------|
| 00 | Tooling check | trivial | compiler/interpreter, build tool, test runner | nothing |
| 01 | Basics | beginner | variables, control flow, functions, I/O | 00 |
| 02 | Data structures | beginner→intermediate | collections, structs/classes, enums, pattern matching | 01 |
| 03 | <Language-specific middle topic> | intermediate | <e.g. ownership, OOP, modules, async> | 01, 02 |
| 04 | Error handling | intermediate | Result/Option, exceptions, panics, error propagation | 01, 02 |
| 05 | Testing | intermediate | unit tests, integration tests, test runners, mocks | 01, 02 |
| 06 | Ecosystem and deps | advanced | package manager, external crates/libs, dependency resolution | 01 |
| 07 | Concurrency (where applicable) | intermediate→advanced | threads, async/await, channels, shared state | 02, 03 |
| 08 | Capstone: <name> | advanced | full real-world application | all previous |

> Not every project applies to every language. Projects that don't
> apply are marked as such and skipped.
